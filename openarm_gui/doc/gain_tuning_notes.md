# OpenArm V10 게인(Gain) 설정 참고 노트

이 문서는 [GitHub PR #69](https://github.com/enactic/openarm_ros2/pull/69) 및 실측 데이터를 기반으로 작성된 게인 설정 권장값입니다. 나중에 `config.yaml`이나 하드웨어 제어 루프를 수정할 때 참고하시기 바랍니다.

## 1. 개요
기존의 OpenArm V10 게인값은 매우 보수적(낮음)으로 설정되어 있어, 정지 마찰력을 이기지 못하거나 추종 오차가 발생하는 경우가 많았습니다. PR #69는 이를 해결하기 위해 게인값을 대폭 상향 조정했습니다.

## 2. 권장 게인 설정값 (Joint 1 ~ 7)

| Joint | 역할 | KP (추천) | KD (추천) | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| J1 | Base Pan | 70.0 | 2.75 | |
| J2 | Should Pitch | 70.0 | 2.5 | |
| J3 | Elbow Pitch | 70.0 | 2.0 | |
| J4 | Wrist Roll | 60.0 | 2.0 | |
| J5 | Wrist Pitch | 10.0 | 0.7 | |
| J6 | Wrist Yaw | 10.0 | 0.6 | |
| J7 | Hand Roll | 10.0 | 0.5 | |

## 3. 그리퍼 (Joint 8) 테스트 결과
- **최종 튜닝 값 (사용자 확인)**: **KP: 8.0**, **KD: 0.2**
- **공식 권장값 (PR #69)**: KP: 16.0, KD: 0.2
- **제어 모델**: **Prismatic (Meters)** 기반 제어 모델 도입
    - ROS 사양(`v10_simple_hardware.cpp`)과 일치하도록 0.0m ~ 0.044m 범위 사용.
- **최종 설정 사항**: 
    - **0.0m (Closed)** / **0.044m (Open)** 기준으로 UI 및 스크립트 적용 완료.
    - 내부적으로 `can_controller`에서 0.044m를 -1.0472 rad로 자동 변환하여 송신.

## 4. 튜닝 시 주의사항
1. **프로그램 충돌**: 메인 GUI와 테스트 스크립트가 동시에 켜져 있으면 서로 다른 목표값(P)을 보내어 모터가 진동할 수 있습니다. 한 번에 하나의 제어 프로그램만 실행하세요.
2. **Zero 설정**: 그리퍼를 수동으로 끝까지 닫은 상태에서 `zero` 명령을 수행하여 기준점을 먼저 잡아야 합니다.
